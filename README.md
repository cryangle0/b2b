## 主链路

1. 后台导入商品 / 图片 / 库存 → 配置现货、期货、订货会 → 经销商多尺码加购 → 提交 → 审核
2. 导出含图片与尺码列的模板 → 填写数量或公式 → 导入修订 → 提交
3. 订单生效后发货 / 回传已发未发 → 经销商查看物流与下载
4. 支付流水、合同、对账单、订购分布
